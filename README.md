# Light — Projeto de Tráfego Orgânico

Projeto de uma página, em HTML/CSS/JavaScript puro, preparado para publicar no GitHub e no Vercel.

## Estrutura

- `index.html` — página principal
- `styles.css` — identidade visual e responsividade
- `script.js` — menu mobile e botão de voltar ao topo
- `assets/images/` — imagens fornecidas para o projeto
- `robots.txt` — instrução básica para mecanismos de busca
- `sitemap.xml` — modelo de sitemap para uma única página
- `vercel.json` — configuração mínima para deploy estático

## Publicação no GitHub

1. Crie um repositório novo.
2. Envie todos os arquivos desta pasta para a raiz do repositório.
3. Faça o commit.

## Publicação no Vercel

1. Entre no Vercel.
2. Importe o repositório do GitHub.
3. Para este projeto não é necessário build command.
4. O diretório de saída é a própria raiz.
5. Faça o deploy.

## Antes de publicar

- Troque `https://SEU-DOMINIO.com/` em `sitemap.xml` pelo domínio real.
- Revise o texto e as imagens.
- Se quiser usar um domínio próprio, adicione-o no Vercel.
- Mantenha a indicação de que esta é uma página informativa independente, caso ela não seja um canal oficial da Light.

## Observação

A palavra-chave central do projeto é **Light**. O conteúdo usa a palavra naturalmente, evitando repetição artificial.
